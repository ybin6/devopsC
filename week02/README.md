# 2주차 내용 정리

## 목표
* WSL2와 Ubuntu를 이용하여 리눅스 실습 환경을 구축
* 기본 리눅스 명령어를 사용하여 파일과 디렉터리 다루기
* Git으로 버전 관리
* GitHub에 저장소를 생성

## 배운 내용
* 서버와 가상화 이해하기
	* 서버/베어메탈/하이퍼바이저/컨테이너
* WSL2로 리눅스 환경 구축하기
	* WSL2/Ubuntu 설치 및 설정
* 리눅스 터미널 익히기
	* 파일, 디렉터리, 권한, 기본 명령어 등
* Git으로 버전 관리 하기
	* 커밋, 버전 이동+비교, 브랜치 
* GitHub에 공유하기
	* 가입, 저장소 생성, 푸시, 레포 제출



## 가상화
* 서버에 적용되는 기술
	* 실제 서버가 존재하지 않더라도 마치 있는 것처럼 만드는 기술
* 물리적인 컴퓨팅 환경 내에서 여러 개의 논리적인 컴퓨팅 환경 만들 수 있는 기술
	* 물리적 = 실제로 존재
	* 논리적 = 가상으로 존재
* 즉, 컨테이너는 서버를 효율적으로 사용하기 위한 **가상화** 기술


## WSL (Windows Subsystem for Linux)
* 특장점
	* 빠른 속도(가상 머신 보다 적은 리소스 사용)
	* 시스템 통합(윈도우 파일 탐색기에서 쉽게 접근 가능)
	* 편리한 개발(bash 명령어를 그대로 사용 가능)

* 파워셸
	* 마이크로소프트가 개발
	* 스크립트 작성 및 실행이 가능한 CLI
	* 관리자 권한으로 실행
